# מדריך הטפסים

המדריך הזה מסביר איך משנים טופס, בונים טופס חדש ומחברים אותו ל-Google Sheets. **אין צורך לדעת לתכנת.** כל מה שכתוב כאן נעשה מתוך האפליקציה ומתוך Sheets.

---

## איך זה עובד בכמה משפטים

1. סקאוטר ממלא טופס באפליקציה ולוחץ **Save**. הטופס נשמר בטלפון.
2. כשיש אינטרנט, הטופס נשלח ל-Google Sheets ונכנס כ**שורה חדשה** בטבלה.
3. הדשבורדים (כמו Team Dashboard) הם נוסחאות שקוראות מהטבלה. הם מתעדכנים לבד, ולא צריך לגעת בהם.

**איך תשובה יודעת לאיזו עמודה להיכנס?** לכל שאלה יש **שם באנגלית** (למשל `team`). התשובה נכנסת לעמודה ב-Sheets שנקראת באותו שם. זה כל הקסם.

| מילה | מה זה |
| --- | --- |

| **פרסום (Publish)** | שליחת הטופס לכל הטלפונים. |

## משימה 1: לשנות טופס קיים (להוסיף או לתקן שאלה)

1. בטאב **Form Editor** מקלידים את הקוד ולוחצים **Unlock**.
2. ליד הטופס לוחצים **Edit**.
3. לוחצים **Open** על הטאב בטופס שרוצים לשנות.
4. לשאלה חדשה: **+ Add question**. לשינוי: **Edit** ליד השאלה.
5. ממלאים את פרטי השאלה (הסבר מלא בהמשך, ב"כל מה שאפשר להגדיר בשאלה").
6. **Done**, ואז **Save** למעלה.
7. **Publish** ← מקלידים את הקוד שוב ← **Publish**.

**מה קורה ב-Sheets?** שאלה חדשה מקבלת עמודה חדשה בסוף הטבלה כשהטופס הראשון איתה נשלח. העמודה נוצרת לבד, וגם מקבלת שם (Named range) בעצמה.

> **אל תשנו id של שאלה שכבר יש לה נתונים.** העמודה ב-Sheets קשורה לשם הזה. אם משנים אותו, התשובות יתחילו להיכנס לעמודה חדשה.

## משימה 2: טופס לעונה חדשה

1. **Form Editor** ← קוד ← **Unlock**.
2. ליד הטופס של השנה שעברה לוחצים **Copy to new year**. כל השאלות מועתקות.
3. בודקים את השם והשנה ← **Create**.
4. משנים את השאלות לפי המשחק החדש (משימה 1).
5. מחברים אותו ל-Sheets (משימה 3).
6. **Save**, ואז **Publish**. אם רוצים שכל הטלפונים יעברו אליו, מדליקים את **All phones scout with this form**.

## משימה 3: לחבר טופס לקובץ Sheets

### שלב א: להכין את קובץ ה-Sheets
1. יוצרים קובץ Google Sheets חדש, או משתמשים בקיים.
2. **Share** ← מוסיפים את `ironih.frc@gmail.com` ← בוחרים **Editor** ← **Send**.
   זה החשבון שכותב את הטפסים לקובץ. בלי השלב הזה שום דבר לא ייכנס.

### שלב ב: להגיד לטופס לאן לכתוב
בעריכת הטופס, בכרטיס **Template** למעלה:
- **Spreadsheet link:** מדביקים את הקישור לקובץ (מהדפדפן, כל הקישור).
- **Spreadsheet tab:** שם הלשונית בקובץ שאליה ייכנסו הטפסים, למשל `Matches`. אם הלשונית לא קיימת, היא תיווצר לבד.

### שלב ג: לבדוק
בכרטיס **Sheet connection** לוחצים **Check the sheet** ומקלידים את הקוד. מופיעה רשימה: כל שאלה ← לאן היא תיכנס.

| מה כתוב | מה זה אומר |
| --- | --- |
| `column E (named range)` | יש עמודה עם השם הזה. מצוין. |
| `column E (header)` | יש עמודה שהכותרת שלה היא השם. גם עובד. |
| `new column + named range` | תיווצר עמודה חדשה בסוף. בסדר אם זה מה שרוצים. |

### שלב ד: לשמור ולפרסם
**Save** ← **Publish** ← קוד.
**חשוב:** עד שהטופס מתפרסם, טפסים לקובץ חדש לא נשלחים. הם מחכים בטלפון עם ההודעה "Publish the template first".

## יש כבר טבלה עם עמודות? (למשל דשבורד שמחכה לעמודות מסוימות)

אם הקובץ חדש וריק, אפשר לדלג על החלק הזה: הכול נוצר לבד.

אם כבר יש טבלה, ורוצים שכל תשובה תיכנס לעמודה **שכבר קיימת**, נותנים לעמודה את ה-id של השאלה כשם:

1. ב-Sheets לוחצים על האות של העמודה למעלה (למשל **E**), כדי לסמן את כל העמודה.
2. בתפריט: **Data** ← **Named ranges**.
3. **Add a range**, ומקלידים את ה-id של השאלה (למשל `team`) ← **Done**.
4. חוזרים על זה לכל עמודה.
5. באפליקציה: **Check the sheet** כדי לוודא שכל שאלה מצאה את העמודה שלה.

אם מישהו יוסיף עמודה באמצע הטבלה, השם זז יחד עם העמודה, ושום דבר לא נשבר.

**דרך קצרה יותר:** אם כותבים בשורה הראשונה של העמודה (הכותרת) בדיוק את ה-id, זה עובד גם בלי Named range.

## דשבורדים וגרפים

- **האפליקציה אף פעם לא כותבת ללשוניות של דשבורד או גרפים.** היא כותבת רק ללשונית של הטופס.
- בנוסחאות של דשבורד אפשר להשתמש **בשם העמודה במקום באות**. ככה הדשבורד לא נשבר אם עמודות זזות.

דוגמאות (`selectedTeam` הוא התא בדשבורד שבו בוחרים קבוצה):
- כמה משחקים יש לקבוצה: `=COUNTIF(team, selectedTeam)`
- ממוצע מחזורים: `=AVERAGEIF(team, selectedTeam, active1Cycles)`
- כמה פעמים נפל: `=COUNTIFS(team, selectedTeam, fell, TRUE)`
- כמה פעמים שיחק הגנה: `=COUNTIFS(team, selectedTeam, active1Role, "*Defense*")`
- כל ההערות על הקבוצה: `=FILTER(comments, team = selectedTeam)`

**איך התשובות נראות ב-Sheets:**
- כן/לא ← `TRUE` / `FALSE`
- בחירה מרובה ← מופרדת ב-` , ` (למשל `Passer , Cycler`). לכן סופרים עם כוכביות: `"*Defense*"`.
- מספרים ← מספרים. טקסט ← טקסט, גם מספר קבוצה (`"8223"`).

**שימו לב:**
- **שם יכול להיות רק במקום אחד בכל הקובץ.** אם תא בדשבורד כבר נקרא `team`, העמודה בטבלה לא תוכל לקבל את השם הזה (היא תעבוד לפי הכותרת). לתאים בדשבורד עדיף לתת שמות אחרים, כמו `selectedTeam`.
- `QUERY` לא עובד עם שמות. לגרפים משתמשים ב-`FILTER`.
- **דשבורד בקובץ אחר:** `=IMPORTRANGE("<sheet link>", "team")` מביא עמודה לפי השם שלה. במקום `<sheet link>` שמים את הקישור לקובץ הנתונים.

## כל מה שאפשר להגדיר בשאלה

**סוג השאלה:**
| סוג | מתי |
| --- | --- |
| **Enum (one choice)** | בחירה אחת מרשימה |
| **EnumList (multiple)** | כמה בחירות מרשימה |
| **Yes / No** | כן או לא |
| **Number (counter)** | ספירה עם כפתורי − ו-+ |
| **Text** / **Long text** | טקסט קצר או ארוך |
| **Header** | כותרת או הסבר בתוך הטופס, בלי תשובה |

**שדות:**
- **Text shown to the scouter:** השאלה כמו שהסקאוטר רואה אותה. אפשר לשלב תשובה קודמת: `Defense on {team}` מציג את מספר הקבוצה.
- **Description:** הסבר קטן מתחת לשאלה.
- **Id:** השם באנגלית. אותיות, מספרים ו-`_`, בלי רווחים.
  - לא לבחור שם שנראה כמו תא, כמו `A1` או `q1`, כי Sheets לא מאשר שם כזה.
  - אם השאלה בעברית, האפליקציה נותנת `question1`, `question2`... עדיף לשנות לשם שמסביר את השאלה, למשל `driverSkill`.
- **Options:** האפשרויות, אחת בכל שורה (רק ב-Enum ו-EnumList).
- **Required:** חובה לענות.
- **Keep for next match:** התשובה נשארת לטופס הבא. מתאים לשם הסקאוטר ולאירוע. במספר המשחק המספר גם עולה ב-1 לבד.
- **Show only if:** השאלה מופיעה רק לפי תשובה אחרת. למשל "איפה הגן" מופיע רק אם הוא שיחק הגנה.

**הגדרות לכל הטופס:**
- **Show this tab only if:** טאב שלם בטופס שמופיע רק לפי תשובה (למשל בלי Auto כשהרובוט לא הגיע).
- **Tab order:** סדר הטאבים לפי תשובה (למשל מי ניצח באוטו).
- **Same value in every row:** ערך שנכנס לכל שורה, בצורה `שם=ערך`. למשל `from=Mariners`.

## בדיקה אחרי כל שינוי

1. ממלאים טופס בדיקה עם קבוצה `9999` ← **Save**.
2. לוחצים **Update** כדי לשלוח מיד.
3. בודקים ב-Sheets שנכנסה שורה, ושכל תשובה בעמודה הנכונה.
4. באפליקציה: **Open** ← מקלידים את המפתח (8 האותיות שהופיעו אחרי השמירה). הטופס צריך להיפתח עם כל התשובות.
5. מוחקים את שורת הבדיקה מ-Sheets.
